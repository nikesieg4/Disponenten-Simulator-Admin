Anmelden

Admin-Passwort. Es wird im Supabase-SQL-Editor mit select admin_set_password('…'); festgelegt.

Neuer Code

Jeder Spieler kann einen Code genau einmal einlösen. „Max. Spieler“ begrenzt, wie viele Spieler ihn insgesamt einlösen können, z. B. 100 = die ersten 100.

Schenken

Einsatzpunkte, Forschungspunkte oder Premium-Tage an einen Spieler. Negative Werte ziehen ab (nie unter 0, Premium endet höchstens sofort). Geschenkte Premium-Tage kosten keine EP und werden an eine laufende Laufzeit angehängt.

Premium & Discord

Alle Spieler mit EP, RP, Premium oder Discord-ID. Spieler mit aktivem Premium und Discord-ID bekommen die Rolle VIP (bis der Bot kommt: von Hand).
